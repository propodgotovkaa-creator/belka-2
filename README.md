# Белочка учится читать

Откройте `index.html` в браузере или разместите его на статическом хостинге. Игровые иллюстрации загружаются из [зафиксированной версии belka](https://github.com/propodgotovkaa-creator/belka/tree/a80e65b1a9d974ed7c81f690abf4540ee878ce0e).

В начале выберите тип слоговой структуры. Прочитайте слово вслух, затем нажмите «Прочитано» или на шишку. За каждое слово белочка поднимается на одну ветку. В каждом уровне 14 слов, на чтение можно тратить сколько угодно времени.

## Слова по уровням

Использована 14-уровневая схема, в которой односложные слова со стечением в начале и в конце идут как два отдельных типа. [Описание схемы](https://xn--b1adcc2a1abhbdq5a0k.xn--p1ai/slogovaya-struktura-slova).

мама, папа, муха, вата, луна, рыба, коза, сова, лиса, липа, мыло, ваза, роза, пила.

### 2. Три открытых слога

### 3. Один закрытый слог

мак, кот, кит, дом, дым, дуб, сыр, сок, нос, рот, суп, мяч, лук, жук.

### 4. Два слога, последний закрытый

### 6. Два слога, стечение и закрытый слог в конце

### 7. Три слога, последний закрытый

### 8. Три слога, одно стечение согласных

комната, конфета, котлета, калитка, собачка, яблоко, улитка, лисичка, колбаса, подушка, палатка, ракетка, капуста, пантера.

### 9. Три слога, стечение и закрытый слог в конце

### 10. Три слога, два стечения согласных
